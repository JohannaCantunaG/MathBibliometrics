# Bibliometric Analysis of Mathematics

This repository contains the code used to reproduce the bibliometric analysis presented in the paper **A bibliometric study of scientific production in mathematics** 

## Repository structure
src/
  Source code.
data/
  Instructions for organizing Scopus exports.
results/
  Figures and tables generated by the notebooks. 

## Data availability

The original Scopus records are not distributed because they are subject to Elsevier's License.
Intructions for downloading the data are available in:  ´data/queries/´
