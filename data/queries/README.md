# Scopus search queries

The data acquisition strategy depended on the number of records returned by each Scopus query. 
- **single_export.md**
  Subjects with fewer than 20,000 records, which can be exported directly from Scopus in a single CSV file.

- **multiple_exports.md** Subjects exceeding the Scopus export limit. These require multiple CSV export that are merged automatically during preprocessing. 

The CSV files should correspond to direct exports from the Scopus web interface.
